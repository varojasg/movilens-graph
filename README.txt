TB1 - MovieLens 1M - Grafo bipartito

Contenido:
- main.py: carga el dataset, construye el grafo completo y genera un subgrafo visual.
- data/ml-1m/: dataset original MovieLens 1M.
- resultados/resumen_grafo_movielens.txt: resumen del grafo completo.
- resultados/grafo_bipartito_movielens.png: imagen del subgrafo para el informe.

Ejecucion:
1. Abrir esta carpeta en Visual Studio Code.
2. Abrir una terminal en la carpeta.
3. Ejecutar:
   pip install -r requirements.txt
4. Ejecutar:
   python main.py
