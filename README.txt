TB1 - MovieLens 1M - Grafo bipartito

Contenido:
- main.py: carga el dataset, construye el grafo completo y genera tres subgrafos visuales.
- data/ml-1m/: dataset original MovieLens 1M.
- resultados/resumen_grafo_movielens.txt: resumen del grafo completo.
- resultados/grafo_bipartito_movielens_1.png: subgrafo 1.
- resultados/grafo_bipartito_movielens_2.png: subgrafo 2.
- resultados/grafo_bipartito_movielens_3.png: subgrafo 3.

Ejecucion:
1. Abrir esta carpeta en Visual Studio Code.
2. Abrir una terminal en la carpeta.
3. Ejecutar:
   pip install -r requirements.txt
4. Ejecutar:
   python main.py
